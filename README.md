## About 
This site is built on a Bootstrap Cover Template and customized with hero animation, an about me-profile card ,a projects showcase and a contact section.

## Features
-----------------------------------------------
- Animated hero section 
 \\ rotating titles

- Sticky navigation header
 \\ with a background that appears on scroll

- Light / Dark / Auto theme toggle 
 \\ using Bootstrap's built in color-mode switcher

- About Me
 \\ with profile photo, contact details and skill badges

- Projects grid 
 \\ highlighting completed work with the links to live demos and source code
 \\ Project Image Credits : https://www.zaio.io/

- Contact Section
 \\ with social links 

\\ Responsive Layour Using Bootstrap's grid system
