This site is a living brag sheet — the one that goes into company inboxes and onto LinkedIn. Like a Pokémon, it evolves as new skills, projects, and features land. The more it is fed, the stronger it gets: from student portfolio to hire-me-now.

**Live site:** [thapelolegote-portfolio.netlify.app](https://thapelolegote-portfolio.netlify.app/)

## About

Personal portfolio for **Thapelo Legote**, an engineering student building toward full-stack and machine learning work. The site introduces who I am, what I can ship, and how to reach me.

It is a static front-end: HTML, custom CSS, and Bootstrap for layout utilities and icons. No build step.

## Features

- **Hero** with rotating roles (Full-Stack AI Engineer, Full-Stack Developer, Machine Learning Engineer)
- **Sticky navigation** to Home, About, Projects, Certifications, and Contact
- **About** card with photo, contact details, and skill badges
- **Projects grid** with live demos and GitHub source
- **Certifications** with verification links
- **Contact** form and social links (LinkedIn, GitHub)
- **Responsive layout** via `responsiveness.css` and Bootstrap
- **Dark / light** styling from `prefers-color-scheme`

## Tech stack

HTML5 · CSS3 · Bootstrap 5 · Bootstrap Icons · Git

Skills highlighted on the site: HTML5, CSS, JavaScript, Bootstrap, Git, React, Redux, Node.js, Express, MongoDB, Firebase, Python, OOP.

## Getting started

Clone the repo and open the site in a browser. Any local static server works; examples:

```bash
git clone https://github.com/ThapeloJL/Thapelolegote_Portfolio.git
cd Thapelolegote_Portfolio
```

```bash
npx serve .
```

Or open `index.html` directly.

## Keep it evolving

Treat this repo as the source of truth for career progress:

2. Update skill badges when a stack is actually in use.
3. Drop new certificates into Certifications with a verification URL.
4. Refresh the About copy so it matches where you are now, not last semester.
